# Torrent Client (Linux Console)

Консольный BitTorrent клиент для Linux, реализующий базовый функционал скачивания файлов.

## Функциональность

- **Парсинг .torrent файлов**: извлечение метаданных о скачиваемом файле
- **Работа с трекером**: HTTP-запросы для получения списка пиров
- **Управление пирами**: подключение, обмен битовыми полями (bitfield)
- **Многопоточная загрузка**: параллельное скачивание частей файла от нескольких пиров
- **Локальное хранилище**: инициализация и сохранение загружаемых частей

## Используемые технологии

- **cpr** - HTTP-запросы к трекеру
- **OpenSSL (SHA)** - хеширование для BitTorrent протокола
- **Сокеты (sys/socket.h)** - сетевое взаимодействие с пирами
- **Poll (sys/poll.h)** - асинхронная работа с сокетами

## Статус

Реализован базовый функционал скачивания файлов через BitTorrent протокол.
