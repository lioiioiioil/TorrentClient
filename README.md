# Torrent-Client-Linux
Консольное приложение Torrent Client для Linux.

# Реализован функционал скачивания файла:
    1. Парсинг torrent-файла, получение информации о скачиваемом файле.
    2. Запрос списка пиров, получение и сохранение их.
    3. Инициализация хранилища частей скачиваемого файла.
    4. Подключение к пирам (установка соединения, запрос поля bitfield).
    5. Непосредственное скачивание частей файла (параллельно от нескольких пиров).
# Использованные сторонние библиотеки:
    cpr/cpr.h - для отправки HTTP-запросов к трекеру, чтобы получить список пиров.
    openssl/sha.h - для SHA хеширования - основа BitTorrent протокола.
    sys/socket.h - для создания и управления сокетами.
    sys/poll.h - для ожидания события на сокете.
